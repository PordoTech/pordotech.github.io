Pordo 使用 Rust 编写，UI 基于 egui/WGPU，音频输出使用 CPAL。Windows 与 macOS
源码构建通过 [remdia](https://github.com/PordoTech/remdia) 组件图完成播放与字幕
音频处理，不链接 FFmpeg。本站面向普通用户维护操作教程；开发资料请阅读仓库文档。

## 品牌与兼容标识

产品由 replayer 更名为 Pordo。已发布的身份标识有意保持稳定：Android
application ID `dev.replayer`、macOS bundle ID `io.github.l-chris.replayer`、
Windows 安装器 AppId、系统凭据命名空间、WebDAV v1 路径
`replayer/v1/devices/` 与加密格式均跨版本兼容；新写入的 sidecar 使用
`.pordo.*` 命名，旧 `.replayer.*` 保持可读。详见
[development.md](https://github.com/PordoTech/pordo/blob/main/docs/development.md)
的品牌与升级兼容一节。
