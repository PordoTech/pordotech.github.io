Pordo 是一个把音乐、视频和漫画放在同一个应用里的媒体工具：Windows 与 macOS
桌面端提供完整功能，Android 端提供音乐、漫画与云同步。你可以按需连接
AI 服务（字幕、歌词、漫画翻译）和自己的 WebDAV 网盘。

## 从哪里开始

1. [安装与更新](/guides/install-update/)：选择适合你平台的安装包，了解更新方式与 macOS 签名状态。
2. [开始使用](/guides/getting-started/)：安装后的第一次打开文件、基本操作和平台差异。
3. 按需要阅读下面的功能指南。

也可以直接前往[下载页](/download/)获取当前版本的安装包。
