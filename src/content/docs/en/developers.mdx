Pordo is written in Rust with an egui/WGPU interface and CPAL audio output.
Windows and macOS source builds play media and process subtitle audio through
[remdia](https://github.com/PordoTech/remdia) component graphs, without linking
FFmpeg. This site maintains user-facing tutorials; development material lives in
the repositories.

## remdia SDK

Repository: [PordoTech/remdia](https://github.com/PordoTech/remdia) — a modular
media SDK that composes system media capabilities (Media Foundation /
VideoToolbox / WIC / ImageIO and friends) as independent components, without
FFmpeg. pordo pins an exact Git revision in Cargo.toml.

## Brand and compatibility identities

The product was renamed from replayer to Pordo. Published identities
intentionally stay stable: Android application ID `dev.replayer`, macOS bundle ID
`io.github.l-chris.replayer`, the Windows installer AppId, OS credential
namespaces, the WebDAV v1 path `replayer/v1/devices/` and the encrypted formats
remain compatible across versions; newly written sidecars use `.pordo.*` names
while old `.replayer.*` files stay readable. See the brand and upgrade
compatibility section of
[development.md](https://github.com/PordoTech/pordo/blob/main/docs/development.md).
