<Aside type="caution" title="数据发送与计费">
AI 功能需要连接你自行配置的第三方 AI 服务：

- 生成字幕/歌词时，**只有显式请求的音频片段**会发送到所选服务，不发送视频
  画面或本地文件路径；漫画翻译会发送**漫画页面图片**。
- 服务商通常按请求计费。取消本地等待**不保证**服务端停止计费；已被接受的
  请求可能仍会产生费用。
- 本地播放与漫画阅读本身不需要 AI 账号。
</Aside>

## 配置服务商与模型

1. 打开 **设置 → AI 提供商**，填入兼容服务的地址、API Key 与可用模型。
2. 拉取模型列表，或手动添加模型 ID。
3. 在 **AI 字幕** 下选择一个**支持音频输入**的模型；漫画翻译单独选择
   **图像编辑**模型。
4. 凭据通过 Windows Credential Manager / macOS Keychain 保存。

模型能力由各服务商决定：字幕/歌词需要音频理解能力，漫画翻译需要“接收图像
编辑请求并返回编辑后图片”的能力，纯文本模型不能用于翻译漫画。

## AI 字幕

1. 打开视频，选择 **字幕 → 生成 AI 字幕**。
2. 生成期间已完成的段落随播放逐步出现；优先生成当前播放位置附近的内容。
3. 字幕菜单支持隐藏、取消与导出。

<Aside type="caution">
生成的字幕**不会自动保存**。请在关闭或切换媒体前，把需要的结果导出为 SRT。
</Aside>

- 输出语言跟随界面语言（中文或英文）；可选双语字幕同时显示原文与目标语言。
- 发送给服务的音频默认转码为 MP3，兼容的服务可选 WAV；模型支持程度因服务商而异。
- 时间轴与措辞是模型估计，失败段落可能留下空隙；正式使用前请检查结果。
- 磁力播放的视频可以用 torrent 缓存中已有的音频生成字幕；缺失音频会延迟生成
  （见[磁力链接播放](/guides/magnet/)）。

## AI 歌词

1. 播放本地歌曲或已完整下载的在线曲目。
2. 点击播放栏**歌词**图标，选择**生成 AI 歌词**。
3. 生成使用 **AI 字幕** 下选择的音频模型，保持歌曲原语言，生成过程中已完成的
   行会实时显示。

结果处理：

| 情况 | 行为 |
| --- | --- |
| 生成成功 | 自动保存为歌曲旁的同名 `.lrc` 文件，下次播放直接加载 |
| **重新生成** | 新结果成功后覆盖已保存的 `.lrc` |
| 取消 / 部分失败 / 未识别到歌词 | 不改动已保存文件；现有歌词保持可见直到新行被识别 |
| 纯器乐段落 | 可能没有歌词 |

识别质量与时间轴精度取决于所选模型。

## 漫画翻译

1. 确认已在 **设置 → AI 提供商** 添加兼容服务，并在漫画设置中选择图像编辑模型。
2. 在阅读器中选择**翻译本页**或**翻译本章**。
3. 预期结果：可在原文、译文与对照三种视图间切换；原始图片始终保留，已缓存的
   翻译结果可复用。

注意事项：

- 翻译必须由你显式发起；取消只停止本地等待，已被接受的请求可能仍会计费。
- 生成图像可能改动画面或误译文字，重要内容请与原文对照确认。
- 单页失败不会删除其原图，也不影响后续页面继续翻译。
- 旧的 PNG/WebP 翻译缓存仍可使用；新的翻译结果使用 JPEG。

## 常见失败与处理

| 现象 | 处理 |
| --- | --- |
| 模型列表拉取失败 | 检查服务地址与 Key；也可手动添加模型 ID |
| 字幕生成中断或有空隙 | 失败段落会留空；检查服务商额度、网络与代理（TUN 环境见磁力指南的路由提示） |
| 翻译返回的还是原图或报错 | 确认所选模型支持图像编辑；纯文本模型不满足要求 |
| 重启后字幕丢失 | 生成字幕不自动保存，需先导出 SRT |
