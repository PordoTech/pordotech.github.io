## 搜索与书架

1. 打开漫画页，搜索 **MangaYun** 或 **Komiic** 书源。
2. 两个书源相互独立：同名作品不会合并，搜索结果分开显示。
3. 打开作品选择章节即可阅读；把作品加入书架后可以检查更新，并从历史记录继续阅读。
4. Komiic 的章节列表可按“章节/卷”类型过滤。

新收藏的作品以当前章节列表为基线；之后新增的未读章节会产生更新提示。

## 阅读方式

- 三种模式：垂直滚动、从左到右翻页、从右到左翻页。
- 缩放、页面位置与阅读进度自动保存。
- 章节按钮打开章节列表；页面滑杆与上一章/下一章控件在书内导航。
- 键盘 Left / Right 在阅读器中翻页。
- Android 端滚到最后一张已解码页面的底部才把章节标记为读完；打开章节本身
  不会清除未读更新。

## Komiic 账号（可选）

配置账号后可获得账号级图片配额并同步登录状态；不配置时保留游客模式。

| 端 | 入口 |
| --- | --- |
| 桌面 | 设置 → 漫画 → Komiic 账号 |
| Android | 漫画页“源设置” |

1. 填写注册邮箱和密码，选择“自动登录”，点击“保存并登录”。
2. 预期结果：显示昵称、登录状态及官网返回的图片用量。
3. 关闭自动登录后仍可手动登录本次会话；重启后恢复游客模式。
4. “退出并清除密码”保留邮箱、关闭自动登录并删除本机密码；即使远端退出请求
   失败，本地也已退出。

<Aside type="note">
凭据存储：Windows 使用 Credential Manager，macOS 使用系统 Keychain，Android
使用 KeyStore 保护的加密存储。密码不写明文配置或日志。Komiic 账号、密码和
会话 Cookie **不参与** WebDAV / API Key 同步。
</Aside>

## 缓存

- 原始页面与封面会缓存到本地；已缓存页面在书源不可用或图片配额用尽时
  仍可继续阅读。
- 在设置中清除缓存不会删除翻译结果、收藏与历史记录。
- 部分上游书源需要适配器更新，或暂不支持；遇到持续失败可在
  [Issues](https://github.com/PordoTech/pordo/issues) 查看或反馈。

## 漫画翻译（仅桌面）

在 **设置 → AI 提供商** 添加兼容服务，并在漫画设置中选择**图像编辑**模型后，
可以对页面或整章发起翻译，支持原文、译文与对照视图。翻译是显式操作，可能
产生服务费用。完整步骤与限制见 [AI 指南](/guides/ai/#漫画翻译)。

Android 端当前没有漫画翻译界面。

## 云同步

漫画收藏（含曾收藏后取消的已跟踪记录）、章节列表、已读/更新标记与阅读进度
通过 WebDAV 与桌面、Android 互通，详见 [WebDAV 云同步](/guides/webdav-sync/)。

## 常见失败与处理

| 现象 | 处理 |
| --- | --- |
| 书源搜索失败或图片加载不出 | 可能是上游波动、配额用尽或需要适配器更新；已缓存页面仍可读 |
| Komiic 登录失败 | 确认邮箱密码正确、账号已激活；连续失败时应用会暂停自动尝试，修改后可手动重试 |
| 进度没有同步到其他设备 | 检查两端是否登录同一 WebDAV 并启用同步，见同步指南的冲突与离线处理 |
