## 第一次打开媒体

1. 启动 Pordo。
2. 用以下任一方式打开本地文件：
   - 通过应用的打开文件入口选择一个或多个文件；
   - 直接把文件拖放到窗口上。
3. 预期结果：应用根据媒体轨道自动进入音乐模式或视频模式并开始播放。
   音乐模式会显示可用的标题、艺术家、专辑、封面与歌词。

<Aside type="tip">
普通打开/拖放会替换当前队列；使用“添加文件”或按住 Shift 拖放则把文件追加到队列。
音乐与视频队列各自独立保存。从队列移除条目不会删除文件。
</Aside>

如果打开失败：

- 视频提示不支持的编解码器时，应用会给出明确错误而不是静默失败。
  当前主验证路径是 MP4/MKV 中的 H.264；详见[音乐与视频](/guides/music-video/)。
- macOS 首次启动被系统拦截时，见[安装与更新](/guides/install-update/#macos-签名与首次启动)中的放行步骤。

## 基本操作与快捷键

| 快捷键 | 作用 |
| --- | --- |
| Space | 暂停/继续播放 |
| Left / Right | 播放中快退/快进；漫画阅读器中翻页 |
| M | 静音/取消静音 |
| F11 | 切换全屏 |
| Esc | 优先退出全屏，其次执行其他返回操作 |
| F / 双击画面 | 视频播放中切换全屏 |

视频与漫画的工具栏在指针靠近窗口边缘时出现；音乐控制常驻显示。

## 进入漫画

1. 打开漫画页。
2. 搜索 MangaYun 或 Komiic 书源中的作品。两个书源相互独立，同名作品也不会合并。
3. 打开作品选择章节开始阅读；加入书架后可以检查更新并从历史记录继续。

详见[漫画阅读](/guides/comics/)。

## 可选：连接 AI 服务与 WebDAV

本地播放和漫画阅读不需要 AI 账号。以下功能全部可选：

- **AI 字幕 / AI 歌词 / 漫画翻译**（仅桌面）：需要先在设置中配置兼容的 AI
  服务商，可能产生服务费用，见 [AI 指南](/guides/ai/)。
- **在线音源**（仅桌面）：需要在设置中配置音源 API Key，见[在线音源](/guides/online-music/)。
- **WebDAV 云同步**（全平台）：使用你自己的网盘同步设置、收藏与进度，见 [WebDAV 云同步](/guides/webdav-sync/)。

<Aside type="caution">
AI 功能会把音频片段或漫画图片发送到你配置的服务商，可能按其价格计费。
在线音源与书源依赖第三方服务的可用性。
</Aside>

## 平台差异

| 项目 | 桌面（Windows / macOS） | Android |
| --- | --- | --- |
| 功能范围 | 音乐、视频、漫画、在线音源、磁力、AI、同步 | 音乐、漫画、收藏、进度、WebDAV 同步 |
| 界面语言 | 中文 / 英文 | — |
| 更新方式 | Windows 应用内检查更新；macOS 前往 Releases | Releases 下载 APK 覆盖安装 |
| 凭据存储 | Windows Credential Manager / macOS Keychain | Android KeyStore |

Android 端当前没有桌面的视频、AI 字幕与漫画翻译界面，详见 [Android 客户端](/guides/android/)。
