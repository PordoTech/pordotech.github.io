## 打开磁力链接

1. 选择**打开磁力链接**，粘贴链接。
2. 等待元数据解析完成，从文件列表中选择一个受支持的文件。
3. 预期结果：播放等待已校验的下载数据后开始；拖动进度条时优先获取请求位置
   附近的数据。

播放启动慢时：做种/peer 数量不足，或代理拦截了 BT 流量，都会延迟播放。

## 任务控制

任务菜单支持：

- **文件选择**：决定下载哪些文件。
- **暂停/继续**：暂停下载会同时暂停播放。
- **停止**：停止任务但**保留已下载的文件**。

<Aside type="caution">
- 应用退出后 torrent 会话不会继续；需要长期做种请使用专门的 BT 客户端。
- 缓存文件**不会自动清理**。手动删除某个任务的缓存前，先停止该任务。
</Aside>

## 支持范围与限制

- **不支持纯 v2 磁力链接**：链接必须包含 v1 的 `btih` 信息哈希；只有 v2
  哈希的磁力无法使用。
- 加密的媒体文件（如 QQ 音乐加密格式）需完整下载后再本地打开，能否解密见
  [在线音源](/guides/online-music/#qq-音乐本地加密文件)。

## 与 AI 字幕配合

磁力播放的视频可以直接生成 AI 字幕：生成会使用 torrent 缓存中已下载的音频。
若对应片段尚未下载，字幕生成会等待或延迟。数据发送与计费说明见
[AI 指南](/guides/ai/)。

## 网络与代理（TUN/系统代理环境）

- 磁力对话框会给出当前环境的路由指引，按其提示调整。
- 使用 TUN 模式或全局代理时，请保证 **AI 服务的代理规则优先于按进程直连的
  规则**，否则字幕生成可能因直连失败而中断。
- 代理拦截 BT 流量时，播放会长时间缓冲；可将 BT 流量排除出代理。

## 常见失败与处理

| 现象 | 处理 |
| --- | --- |
| 元数据一直不出现 | 检查链接完整性（须含 v1 `btih`）、网络与代理是否放行 BT |
| 播放频繁缓冲 | peer 少或代理拦截；等待更多已校验数据或调整路由 |
| 磁盘占用持续增长 | 缓存不自动清理；停止任务后手动删除对应缓存 |
| 字幕生成慢 | 音频尚未下载到缓存；等待或先让任务下载对应片段 |
