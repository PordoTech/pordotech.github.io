## 打开与添加媒体

- 打开一个或多个文件，或直接拖放到窗口。
- **添加文件**或按住 Shift 拖放：追加到当前队列。
- 普通打开/拖放：替换当前队列。
- 音乐与视频队列独立保存；从队列移除条目不会删除文件。

应用根据媒体轨道自动选择音乐或视频模式。

## 队列、收藏与最近播放

- 队列侧栏支持选择、移除和重排条目；拖动重排时先按住条目标题再拖。
- 收藏与最近活动可从媒体页面和主页进入。
- 音乐收藏上的**全部播放**使用当前显示的收藏列表，包括尚未下载到本机的在线曲目。

## 音乐信息与歌词

音乐模式显示可用的标题、艺术家、专辑、封面与歌词：

- 内嵌标签优先；在线曲目的元数据用于补齐缺失信息。
- 同名 `.lrc` 文件可提供逐行时间轴歌词。
- 点击播放栏的**歌词**图标，选择**显示歌词**打开歌词视图。
- 选择**生成 AI 歌词**可以为本地歌曲或已完整下载的在线曲目转写歌词。

<Aside type="caution">
生成 AI 歌词会把歌曲音频片段发送到你配置的 AI 服务商，可能产生费用。
识别与时间轴取决于所选模型；纯器乐段落可能没有歌词。生成成功后自动保存为
同名 `.lrc` 文件；**重新生成**在新结果成功后覆盖该文件；取消、部分失败或
未识别到歌词时不改动已保存文件。详见 [AI 指南](/guides/ai/#ai-歌词)。
</Aside>

## 视频播放

- 工具栏在指针靠近窗口边缘时出现；音乐控制常驻。
- **F** 或双击画面切换全屏；**F11** 也可切换全屏；**Esc** 优先退出全屏。

### 编解码支持范围

| 项目 | 现状 |
| --- | --- |
| 视频主验证路径 | MP4 / MKV 中的 H.264 |
| Windows 视频解码 | 系统 Media Foundation，同步软件解码 |
| macOS 视频解码 | VideoToolbox，H.264 / HEVC（渐进式、8-bit 4:2:0 SDR）；H.264 有真实文件测试覆盖 |
| 不支持的编解码器 | 返回明确错误，不会静默换用其他解码后端 |
| 音频解码 | MP3、AAC、FLAC、ALAC、PCM、Opus 使用系统解码；macOS 另支持 Vorbis；Windows Vorbis 有独立的窄化回退 |
| Dolby | 取决于系统已安装的组件 |

以上依据仓库 remdia 集成文档（main 分支），描述的是当前源码构建；已发布版本
可能使用更早的后端。

### 进度条与定位的已知限制

- 远程纯 MPEG 音频流使用近似的字节/时长定位（避免扫描未下载前缀），VBR
  精度受此限制；本地音频与带时间戳的容器保留精确定位。
- Windows 上 MF 解码 FLAC 目前从文件头预卷：长文件跳转的等待时间可能随
  目标位置增长。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| Space | 暂停/继续播放 |
| Left / Right | 播放中快退/快进；漫画阅读器中翻页 |
| M | 静音/取消静音 |
| F11 | 切换全屏 |
| Esc | 优先退出全屏，其次执行其他返回操作 |
| F / 双击画面 | 视频播放中切换全屏 |

## 常见失败与处理

| 现象 | 处理 |
| --- | --- |
| 打开视频报编解码器不支持 | 确认封装与编码：当前主路径为 MP4/MKV + H.264；其他组合可能不受支持 |
| 拖动进度条后等待较久 | 远程 MPEG 音频与 Windows FLAC 存在上表所列定位限制 |
| 视频没有声音 | 检查 M 键静音状态与系统输出设备；Dolby 内容依赖系统组件 |
| 更多排查 | 见[常见问题](/guides/faq/) |
