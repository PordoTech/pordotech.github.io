## 配置音源

1. 打开 **设置 → 音乐**。
2. 填入音乐源服务的 API Key 并保存。
3. 预期结果：可以搜索 ChKSz 适配器提供的三个音源——网易云音乐、QQ 音乐、酷狗。

搜索不到结果或播放失败时：先确认 API Key 有效，再看是否是个别曲目
“音质不可用”——应用会明确报告不可用，而不是静默替换为其他音质。

## 播放与下载

| 操作 | 行为 |
| --- | --- |
| **播放** | 音源允许时边下载边播放 |
| **下载** | 保存完整文件到下载目录 |

- 已下载的曲目会复用现有文件，不重复下载。
- 下载目录可配置；播放完成后文件保留在该目录。
- 收藏的在线曲目可在其他设备通过 WebDAV 同步看到（先显示元数据，下载后播放）。

## sidecar 文件：移动下载内容时必须一起带走

下载的音乐旁边可能有以下伴随文件：

| 文件 | 内容 |
| --- | --- |
| `.pordo.json` | 曲目元数据（旧版本为 `.replayer.json`，仍可读取） |
| `.pordo-cover.png` | 封面（旧版本为 `.replayer-cover.png`） |
| `.lrc` | 歌词（含 AI 生成后保存的歌词） |

这些信息可能没有内嵌到音频文件中。移动或备份下载的音乐时，请保留同名
sidecar 文件；丢失后封面、元数据与歌词可能不再显示。

## QQ 音乐本地加密文件

部分 QMC / MFLAC / MGG 变体可以播放：

1. 直接打开文件。若播放器请求歌曲密钥（ekey）：
   - 选择**导入歌曲密钥并重试**；或
   - 把 Base64 的 ekey 保存为媒体旁的 `song.mflac.ekey` 之类文件（保留原始扩展名）。
2. 预期结果：解密播放。这是**逐曲**密钥；应用不会读取你的账号凭据，也不会从
   其他应用提取密钥。

支持范围：

- 旧版 QMC1 与受支持的 QMC2 Map/RC4 变体可以打开。
- 部分仅存元数据的变体需要外部 ekey。
- EncV2 与未知 footer 版本**不支持**；仅凭扩展名不能判断兼容性。
- 磁力下载得到的加密文件需先完整下载，再本地打开。

## 常见失败与处理

| 现象 | 处理 |
| --- | --- |
| 搜索无结果 | 检查 API Key 与网络；上游服务波动时稍后再试 |
| 提示音质不可用 | 换一首或换音质；应用不会静默降级 |
| 封面/歌词丢失 | 确认 sidecar 文件与音频在同一目录且同名 |
| 加密文件打不开 | 对照上文支持范围；EncV2 暂不支持 |
