适用平台：Windows · macOS · Android。内容依据 pordo 仓库 main 分支 `893459a`、

<Aside type="caution" title="同步不是媒体备份">
WebDAV 同步覆盖的是设置、收藏与进度等轻量数据，**不上传**本地媒体文件。
它不等同于媒体文件备份，也不能替代你自己的备份方案。
</Aside>

## 配置步骤（桌面）

1. 打开 **设置 → 云同步**，填入 HTTPS WebDAV 服务的地址、用户名与密码
   （建议使用应用专用密码）。
2. 点击**测试连接**。测试只创建、读取并删除一个随机探测对象，不会触碰已有数据。
3. 启用同步。
4. 在另一台设备上使用**同一 WebDAV 账号**重复以上步骤。

预期结果：支持的设置、收藏与进度在设备间合并同步；离线修改保留在本机，
重新连接后自动合并。

## 配置步骤（Android）

1. 入口：音乐页或漫画页右上角**云同步**。
2. 选择与桌面相同的 WebDAV 提供商，填写地址、用户名、应用密码并保存。
3. 可先**测试连接**，再**立即同步**。

Android 的同步时机：启动、回到前台、手动触发；前台运行时每 5 分钟检查一次，
普通变更合并 5 秒、进度变更合并 30 秒后上传，退出前台时尝试提交待处理变化。
出错自动退避 5 分钟，手动同步可立即重试。应用被系统终止后从下次启动继续，
**没有单独的常驻后台服务**。设备 ID 由本机生成并持久保存，不从远端导入。

## 同步范围

| 同步 | 不同步 |
| --- | --- |
| 受支持的服务/模型设置 | 本地媒体文件与路径 |
| 漫画收藏、章节列表、已读/更新标记、阅读进度 | 播放队列 |
| 在线歌曲收藏、播放进度、音源与音质选项 | 下载的音频、封面、漫画页面 |
| 相关偏好设置 | 翻译图片与字幕缓存 |
| （可选、单独加密）API Key | 未收藏且从未跟踪的本地历史 |

补充：

- 跨设备的在线歌曲收藏先显示元数据，下载后才能播放。
- 手机端暂未实现的 AI/字幕选项在合并中保留，不会被删除。
- Komiic 账号、密码与会话 Cookie 不参与同步（见[漫画阅读](/guides/comics/#komiic-账号可选)）。

## API Key 同步（可选，默认关闭）

API Key **默认不上传**。要在设备间同步 Key：

1. 在每台设备上启用 API Key 同步选项。
2. 在所有设备填写**相同的独立同步口令**（至少 12 字符）。Key 使用该口令加密后
   才会写入 WebDAV。
3. 修改口令时需要原口令可用。

<Aside type="note">
WebDAV 密码与同步口令本身都不会上传。口令输错时应用会**停止写入**，而不是用
错误口令覆盖已加密的 Key。凭据在本机分别由 Credential Manager（Windows）、
Keychain（macOS）与 KeyStore（Android）保护。
</Aside>

## 冲突与离线处理

- 同步基于向量时钟与设备文档合并；离线修改保留在本机，重新连接后合并。
- Android 本地修改以字段补丁方式写入最新记录，不用旧数据整体覆盖云端刚合并
  的状态；同步期间发生的新编辑会在请求返回后重新捕获再合并。
- 需要继续上传时界面显示“等待同步”；未完成的操作写入按账户隔离的本地日志。
- 同步完成后，书架/详情与歌曲收藏列表自动刷新；**正在播放或阅读的位置不会被
  远端进度强制跳转**，下次打开时恢复合并后的进度。

## 本地数据位置与空间

| 平台 | 数据目录 |
| --- | --- |
| Windows | `%LOCALAPPDATA%/pordo` |
| macOS | `~/.config/pordo`（设置了 `XDG_CONFIG_HOME` 时随其变化） |

- 对应 `replayer` 目录中的既有配置会自动复用。
- 下载与缓存可能占用较大空间；手动删除磁力缓存前先停止对应任务
  （见[磁力链接播放](/guides/magnet/)）。
- 移动下载的音乐时保留 sidecar 文件（见[在线音源](/guides/online-music/)）。

## 常见失败与处理

| 现象 | 处理 |
| --- | --- |
| 测试连接失败 | 检查地址（HTTPS）、用户名与应用密码；确认网盘允许 WebDAV |
| API Key 未同步 | 确认两端都启用了 Key 同步且口令一致；口令错误时写入会被停止 |
| 进度被“回退” | 合并以最新向量时钟为准；正在阅读/播放中的位置不会被远端强制跳转 |
| Android 提示等待同步 | 网络恢复或手动触发同步即可；错误会自动退避重试 |
